# 💼 Portfolio Website

A modern and responsive **Portfolio Website** built using **React.js** that showcases my skills, projects, and experience through smooth animations, a custom cursor, and an interactive particles background.

---

## 🚀 Features

* 🏠 Home page with an animated introduction
* 👤 About page to share who I am
* 🧠 Skills page to show my technical skills
* 📁 Projects page to display my work
* 💼 Experience page to show my journey
* 💬 Testimonial section
* 📞 Contact page to get in touch
* 🖱️ Custom cursor
* ✨ Animated intro screen
* 🌌 Particles background
* 🍔 Overlay menu for navigation
* 🎞️ Smooth animations using **Motion**
* 📱 Responsive and clean user interface

---

## 🛠️ Built With

* React.js
* JavaScript (ES6)
* Motion (animation library)
* Particles background library
* CSS3

## ⚙️ How It Works

1. The site opens with an **animated intro**.
2. The main page loads with the **particles background** and the **custom cursor**.
3. The visitor uses the **navbar** or the **overlay menu** to move between sections.
4. Each section appears with smooth **Motion** animations.
5. The visitor can read about me, see my skills, projects, and experience, and read testimonials.
6. The visitor can use the **contact page** to get in touch.

## 💡 Challenges Faced

One of the main challenges was combining many visual effects (custom cursor, particles background, intro animation, and page animations) without making the website slow or confusing.

### Solution

* Split every effect into its own reusable component.
* Used **Motion** for smooth, controlled animations instead of heavy custom CSS.
* Kept the particles background lightweight so the pages stay fast.
* Built an overlay menu so navigation stays clean on small screens.
